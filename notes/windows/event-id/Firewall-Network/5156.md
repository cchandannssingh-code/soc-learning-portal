# Windows Security Event ID 5156 - The Windows Filtering Platform Has Allowed a Connection

## Overview

**Event ID:** 5156

**Log Source:** Security

**Category:** Windows Filtering Platform (WFP)

**Description:** The Windows Filtering Platform allowed a network connection.

---

## What Does It Mean?

Event ID 5156 is generated when Windows Firewall permits a network connection.

Think of Event ID 5156 as:

> Windows Firewall reviewed a connection and allowed it.

---

## Why Is It Important?

5156 helps analysts identify:

* Successful network communications
* Lateral movement
* Malware communication
* Command & Control (C2)
* Remote administration activity
* SMB access
* RDP access
* DNS activity

---

## 5156 vs 5157

| Event ID | Meaning            |
| -------- | ------------------ |
| 5156     | Connection Allowed |
| 5157     | Connection Blocked |

### Easy Memory Trick

```text
5156 = Allowed

5157 = Blocked
```

---

# Interview Answer

**Q: What does Event ID 5156 indicate?**

**Answer:**

Event ID 5156 indicates that Windows Filtering Platform allowed a network connection. During investigation, I would identify the process initiating the connection, review the source and destination IP addresses, analyze the destination port and protocol, determine whether the communication is expected, and correlate with process creation events such as 4688 to understand the activity that generated the connection.
