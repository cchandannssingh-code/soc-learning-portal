# Windows Security Event ID 5157 - The Windows Filtering Platform Has Blocked a Connection

## Overview

**Event ID:** 5157

**Log Source:** Security

**Category:** Windows Filtering Platform (WFP)

**Description:** The Windows Filtering Platform blocked a network connection.

---

## What Does It Mean?

Event ID 5157 is generated when Windows Firewall (WFP) blocks a network connection.

Think of Event ID 5157 as:

> "A network connection was attempted but Windows Firewall denied it."

---

## Why Is It Important?

5157 helps identify:

* Blocked network connections
* Firewall rule activity
* Unauthorized communication attempts
* Malware network traffic
* Lateral movement attempts
* Port scanning activity
* Misconfigured applications

---

## Plain English Interpretation

This event means:

> Windows Firewall blocked an inbound UDP connection from 192.168.0.5 attempting to communicate with multicast address 224.0.0.252 on port 5355.

# Port 5355 Deep Dive

## What Is Port 5355?

```text
UDP/5355
```

Used for:

```text
LLMNR
```

(Local Link Multicast Name Resolution)

---

## Why Does LLMNR Exist?

When DNS cannot resolve a hostname:

```text
Workstation
      ↓
DNS Fails
      ↓
LLMNR Broadcast
      ↓
Other Hosts Respond
```

---

## Example

User attempts:

```text
\\fileserver
```

DNS fails.

Windows sends:

```text
Who is fileserver?
```

using:

```text
UDP 5355
```

---

# LLMNR Security Risk

## Problem

Anyone on the network can respond.

Example:

```text

      ↓

      ↓

Attacker Responds
```

## Result

# Interview Questions

## Q: What does Event ID 5157 indicate?

### Answer

Event ID 5157 indicates that Windows Filtering Platform (Windows Firewall) blocked a network connection. During investigation I would identify the application involved, determine the source and destination addresses, review the destination port and protocol, determine whether the traffic was expected, and correlate with process creation events such as 4688 to identify the process responsible.
