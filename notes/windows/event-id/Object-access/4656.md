# Windows Security Event ID 4656 - A Handle to an Object Was Requested

## Overview

**Event ID:** 4656

**Log Source:** Security

**Category:** Object Access

**Description:** A handle to an object was requested.

---

## What Does It Mean?

Event ID 4656 is generated when a process requests access to an object.

The object can be:

* File
* Folder
* Registry Key
* Windows Service
* Active Directory Object
* Printer
* Security Object

Important:

```text
4656 = Access Requested

4663 = Access Performed

4658 = Handle Closed
```

Think of 4656 as:

> "Can I access this object?"

Windows checks permissions before granting access.

---

## Why Is It Important?

Attackers often interact with sensitive objects before modifying them.

Examples:

* Reading files
* Accessing registry keys
* Querying services
* Modifying permissions
* Accessing Active Directory

---

## Example Event

```text
Subject:
    Security ID: S-1-5-20
    Account Name: COMPUTER$
    Account Domain: DOMAIN
    Logon ID: 0x3E4

Object:
    Object Server: SC Manager
    Object Type: SERVICE OBJECT
    Object Name: FirewallService

Process Information:
    Process ID: 0x3c8
    Process Name: C:\Windows\System32\services.exe

Access Request Information:
    Accesses:
        Query status of service
        Start the service

    Access Mask: 0x14
```

---

## Plain English Interpretation

This event means:

> services.exe requested permission to check the status of a Windows service and potentially start it.

---

### What Is Access Mask?

Windows internally stores permissions as bits.

Example:

```text

```

represents:

```text

Start Service
```

---

### Common Access Masks

| Access Mask | Meaning       |
| ----------- | ------------- |
| 0x1         | Query         |
| 0x2         | Change Config |
| 0x4         | Query Status  |
| 0x10        | Start         |
| 0x20        | Stop          |
| 0x10000     | Delete        |
| 0xF01FF     | Full Control  |

# Interview Answer

## Q: What does Event ID 4656 indicate?

### Answer

Event ID 4656 indicates that a process requested a handle to an object such as a file, registry key, service, or Active Directory object. During investigation I would identify the target object, determine which process requested access, review the permissions requested, and correlate with Event ID 4663 to verify whether access actually occurred.
