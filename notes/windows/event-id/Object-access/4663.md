# Windows Security Event ID 4663 - An Attempt Was Made to Access an Object

## Overview

**Event ID:** 4663

**Log Source:** Security

**Category:** Object Access

**Description:** An attempt was made to access an object.

---

## What Does It Mean?

Event ID 4663 is generated when an object is actually accessed.

Unlike:

```text
4656 = Access Requested
```

Event ID 4663 means:

```text
Access Granted
AND
Action Performed
```

Think:

```text
4656
Can I Access This?
      ↓

4663
I Accessed It
      ↓

4658
Done
```

---

## Why Is It Important?

4663 confirms actual activity.

It helps identify:

* File Access
* Registry Access
* Service Access
* Active Directory Access
* Security Configuration Changes
* Data Theft
* Persistence Activity

---

## Why SOC Analysts Care

Many attack chains contain:

```text
4688
Process Created
      ↓

4656
Access Requested
      ↓

4663
Object Accessed
```

Example:

```text
powershell.exe
      ↓

4663
SAM Database Accessed
```

Potential credential theft.

This event means:

> notepad.exe successfully accessed and read the file C:\Sensitive\File.txt.

# Interview Answer

## Q: What does Event ID 4663 indicate?

### Answer

Event ID 4663 indicates that an object was actually accessed. Unlike Event ID 4656, which only records an access request, Event ID 4663 confirms that the requested action occurred. During investigation I would identify the target object, review the process that accessed it, determine the access type (read, write, delete, etc.), and assess whether the activity was expected or potentially malicious.
