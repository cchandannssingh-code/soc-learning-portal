# Windows Security Event ID 4720 - User Account Created

## Overview

**Event ID:** 4720

**Log Source:** Security

**Category:** User Account Management

**Description:** A new local or domain user account has been created.

---

## Why is this Important?

Attackers often create new accounts after gaining access to a system or Active Directory environment. Monitoring Event ID 4720 helps detect:

* Unauthorized account creation
* Persistence mechanisms
* Privilege escalation attempts
* Insider threats
* Misconfigured provisioning processes

---

## Key Fields

| Field                | Description                       |
| -------------------- | --------------------------------- |
| Subject Account Name | User who created the account      |
| Subject Security ID  | SID of the creator                |
| Logon ID             | Session that performed the action |
| New Account Name     | Newly created account             |
| New Account SID      | SID of the new account            |
| User Account Control | Account settings and status       |

---

## Example Event Analysis

### Subject (Creator)

```text
Security ID: domain\aaaa
Account Name: aaaa
Account Domain: domain
```

The user **aaaa** created the new account.

### New Account

```text
Security ID: domain\bbbb
Account Name: bbbb
Account Domain: domain
```

A new user account named **bbbb** was created.

---

## Important Findings from the Event

### Account Disabled

```text
Account Disabled
```

The account exists but cannot be used for logon until enabled.

Look for:

```text
Event ID 4722
```

to determine whether the account was enabled later.

---

### Password Not Required

```text
'Password Not Required' - Enabled
```

This means the account was created without requiring a password.

This should be verified because it may indicate:

* Temporary provisioning
* Service account creation
* Misconfiguration
* Suspicious activity

---

### Password Never Set

```text
Password Last Set: <never>
```

No password has been configured yet.

Check for:

```text
Event ID 4723
Event ID 4724
```

to determine whether a password was later set or reset.

---

### Primary Group ID

```text
Primary Group ID: 513
```

Group ID 513 corresponds to:

```text
Domain Users
```

The account was created as a standard user account.

---

## Investigation Steps

### Step 1: Verify Creator

Determine whether the account creator is authorized to create users.

```text
Creator: aaaa
New User: bbbb
```

Questions:

* Is the creator an administrator?
* Is account creation expected?
* Was a ticket or request submitted?

---

### Step 2: Check if Account Was Enabled

Search for:

```text
Event ID 4722
```

---

### Step 3: Check Password Activity

Search for:

```text
Event ID 4723
Event ID 4724
```

---

### Step 4: Check Group Membership Changes

Search for:

```text
4728 - Added to Domain Security Group
4732 - Added to Local Security Group
4756 - Added to Universal Security Group
```

---

### Step 5: Check Logon Activity

Search for:

```text
Event ID 4624
```

Determine whether the newly created account was used to log in.

---

## SOC Analyst Summary

### Simple Explanation

Event ID 4720 indicates that a new user account has been created.

From this event, a SOC analyst can identify:

* Who created the account
* Which account was created
* When it was created
* Initial account configuration

### Example

```text
Creator Account: aaaa
Created Account: bbbb
```

Meaning:

> User "aaaa" created a new account named "bbbb".

## Interview Answer

**Q: What does Event ID 4720 indicate?**

**Answer:**

Event ID 4720 indicates that a new user account was created. During investigation, I would verify who created the account, whether the creation was authorized, and whether the account was later enabled, modified, added to privileged groups, or used for logon.
