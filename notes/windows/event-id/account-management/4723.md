# Windows Security Event ID 4723 - An Attempt Was Made to Change an Account's Password

## Overview

**Event ID:** 4723

**Log Source:** Security

**Category:** User Account Management

**Description:** An attempt was made to change the password of an account.

---

## What Does It Mean?

Event ID 4723 is generated when a user attempts to change their own password.

This is different from a password reset.

### Password Change vs Password Reset

| Event ID | Action                               |
| -------- | ------------------------------------ |
| 4723     | User changes their own password      |
| 4724     | Another user/admin resets a password |

---

## Key Fields

| Field                | Description                             |
| -------------------- | --------------------------------------- |
| Subject Account Name | User performing the password change     |
| Target Account Name  | Account whose password is being changed |
| Logon ID             | Session performing the action           |

---

## Example Event

### Subject

```text
Security ID: DOMAIN\john
Account Name: john
```

### Target Account

```text
Security ID: DOMAIN\john
Account Name: john
```

In most cases:

```text
Subject = Target
```

Meaning:

> User "john" changed his own password.

---

## Common Scenarios

### Legitimate Activity

* User changes password before expiration
* User updates password voluntarily
* Password policy compliance

### Suspicious Activity

* Service account password change
* Multiple password changes in a short period
* Password changes outside business hours
* Password change immediately followed by privilege escalation

---

## Investigation Steps

### Step 1: Identify the User

Check:

```text
Subject Account Name
Target Account Name
```

Example:

```text
john changed his own password
```

---

### Step 2: Verify Success or Failure

Event 4723 records an attempt.

Review the event status:

```text
Status
Sub Status
```

Common results:

```text
0x0 = Success
```

Other status codes may indicate failure.

---

### Step 3: Check Recent Logons

Search for:

```text
4624 - Successful Logon
4625 - Failed Logon
```

Determine where the password change originated.

---

### Step 4: Check for Suspicious Follow-Up Activity

Search for:

```text
4728 - Added to Security Group
4732 - Added to Local Group
4738 - Account Modified
```

---

## Attack Perspective

Attackers who compromise credentials may:

1. Log in
2. Change password
3. Lock out legitimate user
4. Maintain persistence

Possible chain:

```text
4624 -> 4723 -> 4728
Logon -> Password Change -> Privilege Escalation
```

**Q: What does Event ID 4723 indicate?**

**Answer:**

Event ID 4723 indicates that a user attempted to change their own password. During investigation, I would verify whether the change was successful, identify the source of the activity, review recent logons, and check for any suspicious account modifications following the password change.
