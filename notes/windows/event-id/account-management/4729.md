# Windows Security Event ID 4729 - A Member Was Removed from a Security-Enabled Global Group

## Overview

**Event ID:** 4729

**Log Source:** Security

**Category:** Group Management

**Description:** A member was removed from a security-enabled global group.

---

## What Does It Mean?

Event ID 4729 is generated when a user, computer, or group is removed from a Security Global Group in Active Directory.

This event is the opposite of Event ID 4728.

---

## Why is it Important?

This event indicates that permissions associated with the group have been removed.

### Legitimate Reasons

* User role change
* Employee transfer
* Privilege cleanup
* Offboarding

### Suspicious Reasons

* Removal of administrators
* Privilege stripping
* Insider threat activity
* Attackers removing security team access

---

## Key Fields

| Field                | Description                         |
| -------------------- | ----------------------------------- |
| Subject Account Name | User who removed the member         |
| Member Name          | User/group removed                  |
| Group Name           | Group from which member was removed |
| Group Domain         | Domain containing the group         |

---

## Example Event

### Subject (Who Removed the Member)

```text
Security ID: DOMAIN\AdminUser
Account Name: AdminUser
```

### Removed Member

```text
Member Name: CN=john,CN=Users,DC=domain,DC=com
```

### Group

```text
Group Name: Domain Admins
```

Meaning:

> AdminUser removed john from the Domain Admins group.

---

## How to Interpret

### Normal Activity

```text
AdminUser removed john from HelpDesk Group
```

Possible reasons:

* Job role change
* Access review
* Account cleanup

---

### High-Risk Activity

```text
AdminUser removed SOCAdmin from Domain Admins
```

Potential indicators:

* Insider threat
* Privilege abuse
* Attacker attempting to lock out administrators

---

## Investigation Steps

### Step 1: Identify Who Performed the Action

Check:

```text
Subject Account Name
```

Questions:

* Is the actor authorized?
* Is there an approved change request?

---

### Step 2: Identify the Removed Member

Check:

```text
Member Name
```

Questions:

* Is this a privileged account?
* Is this a service account?
* Is the removal expected?

---

### Step 3: Review the Group

Check:

```text
Group Name
```

High-value groups:

```text
Domain Admins
Enterprise Admins
Administrators
Backup Operators
Account Operators
```

Removal from these groups can significantly affect security.

---

### Step 4: Check Previous Group Additions

Search for:

```text
4728 - Added to Global Group
4729 - Removed from Global Group
```

Example:

```text
4728 -> 4729
Added -> Removed
```

---

### Step 5: Review Logon Activity

Search:

```text
4624 - Successful Logon
4625 - Failed Logon
```

Questions:

* Did the account lose access and then experience failed logons?
* Was there unusual activity before removal?

---

## Common Attack Scenario

An attacker gains admin access and removes legitimate administrators from privileged groups.

Attack chain:

```text
4624 -> 4729 -> 4732
Logon -> Remove Admin -> Modify Access
```

Possible objectives:

* Prevent incident response
* Maintain control of the environment
* Reduce visibility

**Q: What does Event ID 4729 indicate?**

**Answer:**

Event ID 4729 indicates that a member was removed from a security-enabled global group. During investigation, I would verify who performed the removal, identify the affected account, determine the importance of the group, and assess whether the change was authorized or potentially part of malicious activity.
