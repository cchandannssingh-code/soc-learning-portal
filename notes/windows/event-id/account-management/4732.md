# Windows Security Event ID 4732 - A Member Was Added to a Security-Enabled Local Group

## Overview

**Event ID:** 4732

**Log Source:** Security

**Category:** Group Management

**Description:** A member was added to a security-enabled local group.

---

## What Does It Mean?

Event ID 4732 is generated when a user, computer, or group is added to a **Security Local Group**.

This event is commonly seen when users are added to:

* Administrators
* Remote Desktop Users
* Backup Operators
* Power Users
* Custom Local Security Groups

---

## Why is it Important?

Adding a user to a local security group can grant additional permissions on a system.

Attackers frequently abuse this event for:

* Privilege escalation
* Persistence
* Lateral movement
* Administrative access

---

## 4728 vs 4732

| Event ID | Group Type                    |
| -------- | ----------------------------- |
| 4728     | Security-Enabled Global Group |
| 4732     | Security-Enabled Local Group  |

### Easy Memory Trick

```text
4728 = Added to Global Group
4732 = Added to Local Group
```

## Investigation Steps

### Step 1: Identify Who Added the Member

Check:

```text
Subject Account Name
```

Questions:

* Is the actor authorized?
* Is there a change request?
* Is the action expected?

---

### Step 2: Identify the Added Member

Check:

```text
Member Name
```

Questions:

* Is it a normal user?
* Is it a service account?
* Was it recently created?

---

### Step 3: Review the Target Group

Check:

```text
Group Name
```

High-priority groups:

```text
Administrators
Remote Desktop Users
Backup Operators
```

---

### Step 4: Review Related Events

Search for:

```text
4720 - Account Created
4722 - Account Enabled
4732 - Added to Local Group
4624 - Successful Logon
```

Common attack sequence:

```text
4720 -> 4722 -> 4732 -> 4624
Create -> Enable -> Add to Administrators -> Logon
```

---

### Step 5: Check Logon Activity

Search:

```text
4624
```

Questions:

* Did the account log in after receiving privileges?
* Which system was used?
* Was the activity expected?

## Common Attack Scenario

### Local Privilege Escalation

Attacker compromises a standard user account.

Then:

```text

```

adds the user to:

```text
Administrators
```

Result:

```text
Local Administrative Access
```

Potential outcomes:

* Credential dumping
* Service manipulation
* Lateral movement
* Persistence

**Q: What does Event ID 4732 indicate?**

**Answer:**

Event ID 4732 indicates that a member was added to a security-enabled local group. During investigation, I would identify who performed the action, determine which account was added, review the target local group, and assess whether the membership change resulted in privilege escalation or unauthorized access.
