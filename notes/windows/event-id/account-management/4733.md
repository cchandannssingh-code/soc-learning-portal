# Windows Security Event ID 4733 - A Member Was Removed from a Security-Enabled Local Group

## Overview

**Event ID:** 4733

**Log Source:** Security

**Category:** Group Management

**Description:** A member was removed from a security-enabled local group.

---

## What Does It Mean?

Event ID 4733 is generated when a user, computer, or group is removed from a **Security-Enabled Local Group**.

This event is the opposite of Event ID 4732.

---

## Why is it Important?

Removing a user from a local security group removes permissions associated with that group.

### Legitimate Reasons

* User role change
* Access review cleanup
* Employee offboarding
* Least privilege implementation

### Suspicious Reasons

* Removing administrators
* Disabling SOC access
* Insider threat activity
* Attackers reducing visibility

---

## 4732 vs 4733

| Event ID | Meaning                         |
| -------- | ------------------------------- |
| 4732     | Member Added to Local Group     |
| 4733     | Member Removed from Local Group |

### Easy Memory Trick

```text
4732 = Add to Local Group
4733 = Remove from Local Group
```

## Investigation Steps

### Step 1: Identify Who Performed the Action

Check:

```text
Subject Account Name
```

Questions:

* Is the actor authorized?
* Is there an approved request?
* Is the action expected?

---

### Step 2: Identify the Removed Member

Check:

```text
Member Name
```

Questions:

* Is it a privileged account?
* Is it a service account?
* Is the removal expected?

---

### Step 3: Review the Target Group

Check:

```text
Group Name
```

High-value groups:

```text
Administrators
Remote Desktop Users
Backup Operators
```

---

### Step 4: Check Previous Membership Changes

Search for:

```text
4732 - Member Added
4733 - Member Removed
```

Example:

```text
4732 -> 4733
Added -> Removed
```

---

### Step 5: Review Logon Activity

Search:

```text
4624 - Successful Logon
4625 - Failed Logon
```

Questions:

* Did failed logons occur after removal?
* Was access intentionally revoked?
* Was there suspicious activity before removal?

---

## Common Attack Scenario

### Administrative Access Removal

An attacker gains privileged access and removes legitimate administrators.

Attack chain:

```text
4624 -> 4733 -> 4732
Logon -> Remove Admin -> Add Attacker Account
```

Possible objectives:

* Prevent incident response
* Maintain persistence
* Reduce administrative oversight

**Q: What does Event ID 4733 indicate?**

**Answer:**

Event ID 4733 indicates that a member was removed from a security-enabled local group. During investigation, I would identify who performed the action, determine which account was removed, review the target group, and assess whether the removal was authorized or could impact administrative access or security operations.

## Quick Memory

```text
4728 = Add to Global Group
4729 = Remove from Global Group

4732 = Add to Local Group
4733 = Remove from Local Group
```

### SOC Privilege Flow

```text
4732 -> Privilege Granted
4733 -> Privilege Removed
```

If the group is **Administrators** or **Remote Desktop Users**, review the event carefully because it directly impacts system access and privileges.
