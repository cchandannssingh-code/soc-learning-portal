# Windows Security Event ID 4738 - A User Account Was Changed

## Overview

**Event ID:** 4738

**Log Source:** Security

**Category:** User Account Management

**Description:** A user account was modified.

---

## What Does It Mean?

Event ID 4738 is generated whenever the properties of a user account are changed.

This is one of the most important account management events because it can indicate:

* Account configuration changes
* Privilege-related modifications
* Password policy changes
* Account enable/disable changes
* Attacker persistence activity

---

## Why is it Important?

Unlike 4720, 4722, 4725, etc., which represent a single action, **4738 can represent many different account modifications**.

Examples:

* User renamed
* Account unlocked
* Password settings changed
* UAC flags changed
* Smart card requirements modified
* Delegation settings changed

---

## Key Fields

| Field                | Description               |
| -------------------- | ------------------------- |
| Subject Account Name | User who made the change  |
| Target Account Name  | Account that was modified |
| Changed Attributes   | Old vs New values         |

## Common Changes Seen in 4738

### Account Enabled / Disabled

```text
Old UAC Value: 0x15
New UAC Value: 0x10
```

Possible indication:

```text
Account Enabled
```

---

### Password Never Expires Enabled

```text
Password Never Expires
```

Potential persistence mechanism.

---

### Smart Card Requirement Removed

```text
Smart Card Required
```

changed to:

```text
Not Required
```

Potential security weakening.

---

### Delegation Enabled

```text
Trusted For Delegation
```

Potential privilege escalation indicator.

---

### Account Unlocked

```text
Account Lockout Cleared
```

User can authenticate again.

## Investigation Steps

### Step 1: Identify Who Made the Change

Check:

```text
Subject Account Name
```

Questions:

* Is the actor authorized?
* Is there an approved request?

---

### Step 2: Identify the Target Account

Check:

```text
Target Account Name
```

Questions:

* Is it a privileged account?
* Is it a service account?
* Is it a recently created account?

---

### Step 3: Compare Old vs New Values

Review:

```text
Old UAC Value
New UAC Value
```

Look for changes such as:

```text
Password Never Expires
Password Not Required
Account Enabled
Delegation Enabled
```

---

### Step 4: Review Related Events

Search for:

```text
4720 - Account Created
4722 - Account Enabled
4723 - Password Changed
4724 - Password Reset
4725 - Account Disabled
```

---

### Step 5: Review Logon Activity

Search:

```text
4624 - Successful Logon
4625 - Failed Logon
```

Determine whether the account was used after modification.

## SOC Analyst Summary

### Simple Explanation

Event ID 4738 means:

> An existing user account was modified.

### Example

```text
Subject User : AdminUser
Target User  : john
```

Meaning:

> AdminUser changed one or more properties of the account john.

---

## What Should You Check?

Always compare:

```text
Old Value
vs
New Value
```

This tells you exactly what changed.

Common suspicious changes:

* Password Never Expires enabled
* Password Not Required enabled
* Delegation enabled
* Smart Card requirement removed
* Account unlocked unexpectedly

**Q: What does Event ID 4738 indicate?**

**Answer:**

Event ID 4738 indicates that an existing user account was modified. During investigation, I would identify who performed the modification, determine which account was changed, compare old and new values, and assess whether the change introduced security risks such as privilege escalation, weakened authentication, or persistence mechanisms.
