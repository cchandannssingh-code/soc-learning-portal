# Windows Security Event ID 4756 - A Member Was Added to a Security-Enabled Universal Group

## Overview

**Event ID:** 4756

**Log Source:** Security

**Category:** Group Management

**Description:** A member was added to a security-enabled universal group.

---

## What Does It Mean?

Event ID 4756 is generated when a user, computer, service account, or another group is added to a **Security-Enabled Universal Group** in Active Directory.

Think of Event ID 4756 as:

> "An account has been granted permissions through membership in a Universal Security Group."

Unlike Local Groups or Global Groups, Universal Groups can contain members from multiple domains and can be assigned permissions anywhere in the forest.

---

## Why Is It Important?

Adding a member to a Universal Security Group may immediately grant access to:

* Shared folders
* Applications
* Databases
* Enterprise resources
* Cross-domain resources
* Administrative roles

---

### Legitimate Reasons

* New employee onboarding
* Department transfer
* Role or responsibility change
* Project access assignment
* Application access provisioning

---

### Suspicious Reasons

* Privilege Escalation
* Insider Threat
* Unauthorized Access
* Attackers granting themselves permissions
* Persistence through group membership
* Cross-domain privilege abuse

---

## Universal vs Global vs Local Groups

| Group Type | Scope                             | Typical Use                   |
| ---------- | --------------------------------- | ----------------------------- |
| Global     | Same Domain                       | Department or Role Membership |
| Local      | Single Computer / Domain Resource | Resource Permissions          |
| Universal  | Entire Forest                     | Cross-Domain Access           |

---

## Easy Memory Trick

```text
4728 = Add to Global Group

4732 = Add to Local Group

4756 = Add to Universal Group
```

---

## Active Directory Group Scope

```text
Global Group
       ↓
Members from Same Domain

Universal Group
       ↓
Members from Multiple Domains

Local Group
       ↓
Permissions on Resources
```

---

## Plain English Interpretation

This event means:

> User **AdminUser** added **User01** to the Universal Security Group **Finance_Users**, granting that account the permissions associated with the group.

---

# Why Universal Groups Matter

Universal Groups are replicated across the Global Catalog.

This means:

```text
One Group
      ↓

Accessible Across

Domain A

Domain B

Domain C
```

A single membership change may affect access across an entire Active Directory forest.

Because of this, changes to Universal Groups should be monitored carefully.

# Subject Section

## Security ID

### Purpose

Identifies who performed the action.

Example:

```text
DOMAIN\AdminUser
```

---

### Investigation Questions

* Is this an administrator?
* Is this a delegated administrator?
* Is the account expected to modify groups?

---

## Account Name

Example:

```text
AdminUser
```

The account that performed the group membership change.

One of the most important investigation fields.

---

## Account Domain

Example:

```text
DOMAIN
```

Shows the domain of the account performing the action.

---

## Logon ID

Example:

```text
0x1A5050247
```

Unique session identifier.

Correlate with:

```text
4624
4672
4688
```

to identify:

* Source IP
* Logon Type
* Privilege Level
* Processes executed

---

# Member Section

## Security ID

Example:

```text
DOMAIN\User01
```

Identifies the account that was added.

This may be:

* User
* Computer
* Service Account
* Group

---

## Account Name

Example:

```text
CN=User01,OU=Users,DC=Company,DC=Local
```

This is the Distinguished Name (DN) of the object.

---

## Understanding Distinguished Names (DN)

Example:

```text
CN=User01
OU=Users
DC=Company
DC=Local
```

Meaning:

| Component | Meaning                   |
| --------- | ------------------------- |
| CN        | Common Name (Object Name) |
| OU        | Organizational Unit       |
| DC        | Domain Component          |

---

## Investigation Questions

* Is this account privileged?
* Is it a service account?
* Is it newly created?
* Is the membership expected?

---

# Group Section

## Security ID

Example:

```text
DOMAIN\Finance_Users
```

Unique SID of the Universal Group.

---

## Account Name

Example:

```text
Finance_Users
```

One of the most important fields.

Represents the group receiving the new member.

Questions:

* Is the group privileged?
* Is it business critical?
* Does it grant administrative rights?

---

## Account Domain

Example:

```text
DOMAIN
```

Shows where the group exists.

Useful in multi-domain environments.

---

# SOC Analyst Summary

### Simple Explanation

Event ID **4756** means:

> A user, computer, or group was added to a **Security-Enabled Universal Group**, potentially granting access across multiple domains in the Active Directory forest.
