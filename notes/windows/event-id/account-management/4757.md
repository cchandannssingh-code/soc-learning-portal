# Windows Security Event ID 4757 - A Member Was Removed from a Security-Enabled Universal Group

## Overview

**Event ID:** 4757

**Log Source:** Security

**Category:** Group Management

**Description:** A member was removed from a security-enabled universal group.

---

## What Does It Mean?

Event ID 4757 is generated when a user, computer, service account, or another group is removed from a **Security-Enabled Universal Group** in Active Directory.

Think of Event ID 4757 as:

> "An account has lost permissions because it was removed from a Universal Security Group."

Unlike Local Groups or Global Groups, Universal Groups can grant access across multiple domains in an Active Directory forest. Removing a member may revoke access to enterprise-wide resources.

---

## Why Is It Important?

Removing a member from a Universal Security Group may immediately remove access to:

* Enterprise applications
* Shared folders
* Databases
* Cross-domain resources
* Administrative roles
* Business applications

---

### Legitimate Reasons

* Employee offboarding
* Department transfer
* Access review cleanup
* Role change
* Least privilege implementation

---

### Suspicious Reasons

* Insider Threat
* Unauthorized privilege removal
* Attackers removing administrators
* Disabling security team access
* Defense evasion
* Covering malicious activity

---

## Universal vs Global vs Local Groups

| Group Type | Scope                             | Typical Use                   |
| ---------- | --------------------------------- | ----------------------------- |
| Global     | Same Domain                       | Department or Role Membership |
| Local      | Single Computer / Domain Resource | Resource Permissions          |
| Universal  | Entire Forest                     | Cross-Domain Access           |

# Why Universal Groups Matter

Universal Groups are replicated to the Global Catalog and are available throughout the Active Directory forest.

Removing a member may affect access across multiple domains.

Example:

```text id="d9vkib"
Universal Group
        ↓

Domain A

Domain B

Domain C
```

One membership removal can impact access to enterprise-wide resources.

# Additional Information

## Privileges

Example:

```text id="4ow8ie"
(blank)
```

### What Does This Mean?

The **Privileges** field lists any special Windows privileges used while performing the operation.

In most environments, this field is:

```text id="dwg3w6"
Blank
```

This is completely normal and does **not** indicate an error or failed operation.

If privileges are listed (for example, `SeSecurityPrivilege` or `SeTakeOwnershipPrivilege`), it may indicate that elevated privileges were required to complete the action and should be reviewed in the context of the account performing the change.

# SOC Analyst Summary

### Simple Explanation

Event ID **4757** means:

> A user, computer, or group was removed from a **Security-Enabled Universal Group**, causing that object to lose the permissions granted through the group's membership.
