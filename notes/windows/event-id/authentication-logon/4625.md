# Windows Security Event ID 4625 - An Account Failed to Log On

## Overview

| Field       | Value                                                         |
| ----------- | ------------------------------------------------------------- |
| Event ID    | 4625                                                          |
| Log Source  | Security                                                      |
| Category    | Authentication / Logon Failure                                |
| Severity    | Low to Critical (depends on volume, account, and source)      |
| Description | Generated whenever Windows rejects an authentication attempt. |

---

## What Does It Mean?

Event ID 4625 indicates that an authentication attempt failed.

Windows received credentials but did not allow access.

Think of Event ID 4625 as:

> "Authentication failed."

The event records:

* Who attempted to authenticate
* Which account was targeted
* Why authentication failed
* Where the request originated
* Which authentication protocol was used

---

## Why Is It Important?

Event ID 4625 is one of the most valuable security events for SOC analysts because many attacks start with failed authentication attempts.

Examples:

* Brute Force Attacks
* Password Spraying
* Credential Stuffing
* User Enumeration
* Service Account Abuse
* Misconfigured Applications

---

### Legitimate Reasons

* User typed wrong password
* Password recently changed
* Cached credentials outdated
* Service account password expired
* User entered wrong username

---

### Suspicious Reasons

* Password spraying
* Brute force attacks
* Credential stuffing
* User enumeration
* Lateral movement attempts
* Automated attack tools

---

## Easy Memory Trick

```text
4624 = Success
4625 = Failure
```

```text
24 = Access Granted
25 = Access Denied
```

# Authentication Failure Flow

```text
User Provides Credentials
           ↓
Windows Validates Credentials
           ↓
Validation Fails
           ↓
Event ID 4625 Generated
           ↓
Access Denied
```

# Why SOC Analysts Care About 4625

Many attack chains begin with multiple 4625 events.

Example:

```text
4625
4625
4625
4625
     ↓
4624
```

Meaning:

```text
Multiple Failed Attempts
          ↓
Successful Login
```

This pattern is commonly seen during:

* Brute Force Attacks
* Password Guessing
* Credential Attacks


# Subject Section Deep Dive

## What Is Subject?

The Subject section identifies:

> Who attempted to perform the logon operation.

Unlike Event ID 4624, the Subject section in 4625 is often empty.

Many analysts incorrectly assume this is suspicious.

In reality, it is usually normal.

---

## Security ID

### Purpose

Identifies the account context that initiated the authentication request.

Example:

```text id="d4q0vz"
DOMAIN\AdminUser
```

---

### Common Values

| Value           | Meaning         |
| --------------- | --------------- |
| DOMAIN\User     | Domain User     |
| COMPUTER\User   | Local User      |
| SYSTEM          | Local System    |
| LOCAL SERVICE   | Local Service   |
| NETWORK SERVICE | Network Service |
| S-1-0-0         | NULL SID        |

---

### NULL SID

Example:

```text id="dbud2u"
S-1-0-0
```

Meaning:

Windows could not associate authentication attempt with a user context.

Very common in:

* Failed logons
* Network authentication
* External authentication attempts

Usually normal.

---

## Account Name

### Purpose

Account context initiating authentication.

Example:

```text id="7zsv9n"

```

or

```text id="nxgjlh"

```

---

### Blank Account Name

Example:

```text id="0oxbrh"
-
```

Most common value in 4625.

Meaning:

Authentication failed before Windows could establish user context.

Usually not suspicious.

---

## Account Domain

### Purpose

Examples:

```text id="kzq8to"

```

```text id="5pgx2v"

```

## Logon ID

### Purpose

Session identifier.

Example:

```text id="0qh7yl"
0x0
```

```text id="9hmj2h"
0x0
```

---

### Why It Matters

Successful logons create meaningful Logon IDs.

Failed logons often do not.

This is expected.

# Attack Scenarios

## Why Attack Scenarios Matter

Most analysts learn:

```text
4625 = Failed Logon
```

However, mature SOC analysts think:

```text
Why Did It Fail?
```

A single 4625 may be user error.

Hundreds of 4625s may indicate an active attack.

---

# Scenario 1 - Brute Force Attack

## What Is Brute Force?

An attacker repeatedly attempts different passwords against the same account.

Example:

```text
User: Administrator

Password1
Password2
Password3
Password4
Password5
```

---

## Event Pattern

```text
4625
4625
4625
4625
4625
```

Same:

```text
Account Name
```

Different password attempts.

---

## Example

```text
Source IP:
10.73.236.225

Target Account:
Administrator

4625 Count:
250
```

---

## Investigation Questions

* How many failures occurred?
* Did account lock out?
* Was authentication successful later?
* Is source IP known?

---

## Escalation Pattern

```text
4625
4625
4625
4625
     ↓
4624
```

Meaning:

```text
Password Guessing
       ↓
Success
```

High severity.

---

# Scenario 2 - Password Spray Attack

## What Is Password Spraying?

Instead of attacking one account with many passwords:

Attacker uses:

```text
One Password
```

Against:

```text
Many Accounts
```

---

## Example

```text
User1
User2
User3
User4
User5
```

Password:

```text
Winter2025!
```

---

## Event Pattern

```text
4625 User1
4625 User2
4625 User3
4625 User4
4625 User5
```

Same:

```text
Source IP
```

---

## Why Attackers Use It

Avoids:

```text
Account Lockout
```

More stealthy than brute force.

---

## Detection Logic

```text
Multiple Accounts
       ↓
Same Source IP
       ↓
Same Time Window
       ↓
4625
```

Potential password spray.

---

## Mistake 1

```text

```

Reality:

Most are:

```text

```

---

## Mistake 2

```text
Ignoring Source IP
```

Reality:

Source IP often reveals attacker infrastructure.

---

## Mistake 3

```text
Ignoring Status Codes
```

Reality:

Status/SubStatus explain exact failure reason.

## Mistake 4

```text

```

Reality:

```text

```

```text

```

after:

```text
4625
```

# Interview Questions

## Q1. What does Event ID 4625 indicate?

### Answer

Event ID 4625 indicates that Windows rejected an authentication attempt.

---

## Q2. Which fields are most important?

### Answer

Review:

```text
Account Name
Status
SubStatus
Source IP
Logon Type
Authentication Package
```

---

## Q3. Difference Between Status and SubStatus?

### Answer

```text
Status
```

Provides:

```text
General Failure Reason
```

---

```text
SubStatus
```

Provides:

```text
Exact Failure Reason
```

---

## Q4. Which SubStatus Code Indicates Wrong Password?

### Answer

```text
0xC000006A
```

Wrong password.

---

## Q5. Which SubStatus Indicates User Does Not Exist?

### Answer

```text
0xC0000064
```

User does not exist.

---

## Q6. Why Correlate 4625 With 4624?

### Answer

Pattern:

```text
4625
4625
4625
     ↓
4624
```

may indicate successful brute force or password guessing.
