# Windows Security Event ID 4634 - An Account Was Logged Off

## Overview

| Field       | Value                                                              |
| ----------- | ------------------------------------------------------------------ |
| Event ID    | 4634                                                               |
| Log Source  | Security                                                           |
| Category    | Session Management                                                 |
| Severity    | Informational                                                      |
| Description | Generated when a logon session ends and the account is logged off. |

---

## What Does It Mean?

Event ID 4634 indicates that a logon session was terminated.

Think of Event ID 4634 as:

> "The session no longer exists."

Unlike Event ID 4647, Event ID 4634 does not necessarily mean the user manually logged off.

---

## Why Is It Important?

Event ID 4634 helps analysts determine:

* Session end times
* Session duration
* User activity timelines
* RDP session termination
* Service account session termination
* Authentication lifecycle

# Interview Answer

## Q: What does Event ID 4634 indicate?

### Answer

Event ID 4634 indicates that a logon session ended and the account was logged off. Unlike Event ID 4647, it does not necessarily mean the user manually logged off. During investigation, I would correlate the event with Event ID 4624 using the Logon ID, calculate session duration, and review any privileged or suspicious activity that occurred during the session.
