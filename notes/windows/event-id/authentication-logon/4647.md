# Windows Security Event ID 4647 - User Initiated Logoff

## Overview

| Field       | Value                                                            |
| ----------- | ---------------------------------------------------------------- |
| Event ID    | 4647                                                             |
| Log Source  | Security                                                         |
| Category    | Session Management                                               |
| Severity    | Informational                                                    |
| Description | Generated when a user initiates a logoff from a Windows session. |

---

## What Does It Mean?

Event ID 4647 indicates that a user explicitly initiated a logoff.

Think:

> The user intentionally ended their session.

Unlike Event ID 4634, which simply indicates that a session ended, Event ID 4647 specifically shows that the user requested the logoff.

---

## Why Is It Important?

Helps analysts determine:

* When a user ended a session
* Whether a session was closed normally
* User activity timelines
* Session duration
* Insider threat investigations

# Interview Answer

## Q: What does Event ID 4647 indicate?

### Answer

Event ID 4647 indicates that a user explicitly initiated a logoff from a Windows session. It is commonly correlated with Event ID 4624 (successful logon) and Event ID 4634 (session termination) to build a complete user session timeline.
