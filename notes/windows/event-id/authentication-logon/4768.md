# Windows Security Event ID 4768 - A Kerberos Authentication Ticket (TGT) Was Requested

## Overview

| Field       | Value                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------ |
| Event ID    | 4768                                                                                                         |
| Log Source  | Security                                                                                                     |
| Category    | Kerberos Authentication                                                                                      |
| Severity    | Informational (Can become High/Critical depending on context)                                                |
| Description | Generated when a user or computer requests a Kerberos Ticket Granting Ticket (TGT) from a Domain Controller. |

---

## What Does It Mean?

Event ID 4768 indicates that a client requested a Kerberos Ticket Granting Ticket (TGT) from a Domain Controller.

A TGT is the first ticket issued during Kerberos authentication.

Think of Event ID 4768 as:

> "The user is asking Active Directory for permission to authenticate."

If successful:

```text
4768
TGT Issued
     ↓

4769
Service Ticket Requested
     ↓

4624
Access Granted
```

---

## Why Is It Important?

Event ID 4768 is useful for detecting:

* Initial authentication activity
* Kerberos abuse
* Password spraying
* AS-REP Roasting
* Suspicious account activity
* Legacy encryption usage
* Authentication failures

---

# Kerberos Fundamentals

## What Is a TGT?

TGT stands for:

```text
Ticket Granting Ticket
```

The TGT acts like a temporary identity card.

```text

```

```text

 ↓
Requests Service Ticket
 ↓
4769
```

# Result Code

## Purpose

Indicates whether the TGT request succeeded or failed.

Think:

```text id="ifqjbp"

```


Meaning:

```text id="1vdp6r"

```

Low concern.

---

## 0x25

Meaning:

```text id="vl7nuy"

```

```text id="afotn9"

```

and

```text id="mwh6j5"

```

# Common Attack Scenarios

## Scenario 1 - Password Spraying

### What Is Password Spraying?

Attacker attempts:

```text
One Password
        ↓
Many Accounts
```

Example:

```text
Summer2025!

      ↓

user1
user2
user3
user4
user5
```

---

### Event Pattern

```text
4768
Result Code = 0x18

4768
Result Code = 0x18

4768
Result Code = 0x18
```

Different users.

Same source IP.

---

### Investigation Indicators

Review:

```text
Client Address
```

Look for:

```text
Many Users
      ↓
Same Source IP
      ↓
0x18
```

---

### Example

```text

      ↓

John
Mike

      ↓

```

```text

```

# Scenario 3 - AS-REP Roasting

## What Is AS-REP Roasting?

Kerberos attack targeting accounts with:

```text
Do Not Require Pre-Authentication
```

enabled.

---

### Normal Flow

```text
User
     ↓
Pre-Authentication
     ↓
TGT Issued
```

---

### Vulnerable Flow

```text
User
     ↓
No Pre-Authentication
     ↓
TGT Issued
     ↓
Offline Password Cracking
```

---

### Why Dangerous?

Attacker can request TGT without knowing password.

Then:

```text
TGT Hash
     ↓
Offline Cracking
```

---

### Investigation Questions

* Does account require pre-authentication?
* Is account privileged?
* Is service account involved?

---

# Scenario 4 - Golden Ticket Activity

### What Is Golden Ticket?

Forged Kerberos TGT.

Requires compromise of:

```text
krbtgt
```

account.

---

### Attack Flow

```text
KRBTGT Hash Stolen
         ↓
Golden Ticket Created
         ↓
Unlimited Kerberos Access
```

---

### Analyst Indicators

Review:

```text
4768
```

Look for:

* Unusual lifetimes
* Unusual encryption types
* Unusual account behavior

# Interview Questions

---

---

RC4 is an older Kerberos encryption type frequently associated with legacy systems and Kerberoasting investigations.
