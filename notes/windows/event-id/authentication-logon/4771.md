# Windows Security Event ID 4771 - Kerberos Pre-Authentication Failed

## Overview

| Field       | Value                                                         |
| ----------- | ------------------------------------------------------------- |
| Event ID    | 4771                                                          |
| Log Source  | Security                                                      |
| Category    | Kerberos Authentication                                       |
| Severity    | Informational (Can become High/Critical depending on context) |
| Description | Generated when Kerberos pre-authentication fails.             |

---

## What Does It Mean?

Event ID 4771 indicates that a Kerberos authentication request failed during the pre-authentication stage.

Before a Domain Controller issues a Kerberos Ticket Granting Ticket (TGT), it verifies the user's identity.

If verification fails:

```text
4771
```

is generated.

Think of Event ID 4771 as:

> "Kerberos authentication was attempted but failed before a TGT could be issued."

---

## Authentication Flow

### Successful Kerberos Authentication

```text
User Enters Credentials
          ↓
4768
TGT Request
          ↓
Password Validated
          ↓
TGT Issued
          ↓
4769
Service Ticket Request
```

---

### Failed Kerberos Authentication

```text
User Enters Credentials
          ↓
4768
TGT Request
          ↓
Password Validation Fails
          ↓
4771
Generated
```

---

## Why Is It Important?

4771 is heavily used to detect:

* Password Guessing
* Password Spraying
* Brute Force Attacks
* Kerberos Enumeration
* Credential Attacks
* Service Account Abuse

---

## Example Event

```text
Account Information:
    Account Name:

Service Information:
    Service Name:
    krbtgt

Network Information:
    Client Address:
    10.73.252.184

Additional Information:
    Failure Code:
    0x18

    Pre-Authentication Type:
    2
```

---

## Plain English Interpretation

This event means:

> A system at 10.73.252.184 attempted Kerberos authentication against Active Directory, but pre-authentication failed because the supplied password was incorrect.

---

# Kerberos Authentication Overview

## What Is Kerberos?

Kerberos is Microsoft's preferred authentication protocol in Active Directory environments.

Purpose:

```text
User
 ↓
Domain Controller
 ↓
Ticket Granting Ticket
 ↓
Service Ticket
 ↓
Access Granted
```

---

## Why Kerberos Uses Pre-Authentication

Without pre-authentication:

```text
Attackers
      ↓
Request TGT
      ↓
Offline Password Cracking
```

would be easier.

Pre-authentication forces the client to prove knowledge of the password before receiving a TGT.

```text id="y6srh7"

```


