# Windows Security Event ID 4657 - A Registry Value Was Modified

## Overview

| Field       | Value                                                       |
| ----------- | ----------------------------------------------------------- |
| Event ID    | 4657                                                        |
| Log Source  | Security                                                    |
| Category    | Registry Auditing                                           |
| Severity    | Medium (Can become Critical depending on registry location) |
| Description | Generated when an existing registry value is modified.      |

---

## What Does It Mean?

Event ID 4657 indicates that a registry value was changed.

Think of Event ID 4657 as:

> "A registry setting was modified."

Unlike:

```text
4656
```

which records access requests,

and

```text
4663
```

which records object access,

Event ID 4657 specifically records:

```text
Registry Value Changed
```

---

## Why Is It Important?

Registry modifications can impact:

* System Configuration
* Security Settings
* Persistence
* Services
* Startup Programs
* Defender Configuration
* RDP Configuration
* User Experience

---

## Why SOC Analysts Care

Many attackers establish persistence through the registry.

Example:

```text
4688
PowerShell
      ↓

4657
Run Key Modified
      ↓

Persistence
```

---

## Example Event

```text
Subject:
    Security ID: S-1-5-18
    Account Name: SYSTEM
    Account Domain: DOMAIN
    Logon ID: 0x3E7

Object:
    Object Name:
    \REGISTRY\MACHINE\SOFTWARE\Vendor\Product

    Object Value Name:
    Stop Time

    Handle ID:
    0x724

    Operation Type:
    Existing registry value modified

Process Information:
    Process ID:
    0x1ed4

    Process Name:
    C:\Program Files\Vendor\Product\service.exe

Change Information:
    Old Value Type:
    REG_SZ

    Old Value:
    1782078344

    New Value Type:
    REG_SZ

    New Value:
    1782078505
```

---

## Plain English Interpretation

This event means:

> The process service.exe modified an existing registry value named "Stop Time" under the specified registry key.

# Interview Answer

## Q: What does Event ID 4657 indicate?

### Answer

Event ID 4657 indicates that a registry value was modified. During investigation I would identify the registry path, determine the specific value that changed, compare the old and new values, identify the process responsible for the modification, and assess whether the change affects persistence, security controls, startup behavior, or system configuration.
