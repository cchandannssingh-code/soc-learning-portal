# Windows Security Event ID 4698 - A Scheduled Task Was Created

## Overview

| Field       | Value                                                               |
| ----------- | ------------------------------------------------------------------- |
| Event ID    | 4698                                                                |
| Log Source  | Security                                                            |
| Category    | Scheduled Task Management                                           |
| Severity    | Medium (Can become Critical depending on task content)              |
| Description | Generated when a new Scheduled Task is created on a Windows system. |

---

## What Does It Mean?

Event ID 4698 indicates that a new Windows Scheduled Task was created.

Think of Event ID 4698 as:

> "Something configured Windows to automatically execute in the future."

---

## Why Is It Important?

Scheduled Tasks are commonly used for:

### Legitimate Reasons

* System Maintenance
* Software Updates
* Log Collection
* Backups
* Monitoring Agents

---

### Suspicious Reasons

* Persistence
* Malware Execution
* Ransomware Deployment
* PowerShell Execution
* Credential Theft
* Delayed Payload Execution

---

## Why SOC Analysts Care

Attackers frequently create Scheduled Tasks because:

```text id="7j0hxf"

      ↓
Task Executes
      ↓
Attacker Regains Access
```

Persistence achieved.

# Interview Answer

## Q: What does Event ID 4698 indicate?

### Answer

Event ID 4698 indicates that a new Scheduled Task was created. During investigation I would review the account responsible, task name, task XML content, execution triggers, command line, privilege level, and any related 4688 process creation events to determine whether the task was created for legitimate administration or malicious persistence.
