# Windows Security Event ID 4699 - A Scheduled Task Was Deleted

## Overview

| Field       | Value                                                                 |
| ----------- | --------------------------------------------------------------------- |
| Event ID    | 4699                                                                  |
| Log Source  | Security                                                              |
| Category    | Scheduled Task Management                                             |
| Severity    | Medium (Can become High/Critical depending on context)                |
| Description | Generated when an existing Scheduled Task is deleted from the system. |

---

## What Does It Mean?

Event ID 4699 indicates that a Scheduled Task was removed from Windows Task Scheduler.

Think of Event ID 4699 as:

> "A Scheduled Task no longer exists."

This event is the opposite of:

```text
4698
=
Scheduled Task Created
```

---

## Why Is It Important?

Scheduled Tasks are commonly used for:

### Legitimate Reasons

* Application Uninstallation
* Maintenance Cleanup
* Software Updates
* Scheduled Task Retirement
* Administrative Cleanup

---

### Suspicious Reasons

* Removing Evidence
* Disabling Security Tasks
* Removing Monitoring Tasks
* Covering Tracks
* Persistence Cleanup After Attack

---

## Why SOC Analysts Care

Attackers often create persistence and later remove it.

Example:

```text
4698
Task Created
      ↓

Malicious Activity
      ↓

4699
Task Deleted
```

The deletion may indicate:

* Evidence Removal
* Anti-Forensics
* Malware Cleanup
* Attack Completion

# Interview Answer

## Q: What does Event ID 4699 indicate?

### Answer

Event ID 4699 indicates that a Scheduled Task was deleted from the system. During investigation I would identify the deleted task, determine its purpose, identify the account that performed the deletion, correlate the event with related 4698 task creation events, review associated 4624 logon activity and 4688 process execution events, and assess whether the deletion was authorized or an attempt to remove persistence or security controls.
