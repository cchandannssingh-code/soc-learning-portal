# Windows Security Event ID 4700 - A Scheduled Task Was Enabled

## Overview

| Field       | Value                                                |
| ----------- | ---------------------------------------------------- |
| Event ID    | 4700                                                 |
| Log Source  | Security                                             |
| Category    | Scheduled Task Management                            |
| Severity    | Medium (Can become High depending on the task)       |
| Description | Generated when a disabled Scheduled Task is enabled. |

---

## What Does It Mean?

Event ID 4700 indicates that a previously disabled Scheduled Task was enabled and can now execute again.

Think of Event ID 4700 as:

> "A scheduled task that was inactive is now allowed to run."

---

## Why Is It Important?

Enabling a task may seem harmless, but it can restore:

* Persistence
* Malware Execution
* Administrative Automation
* Security Monitoring
* Backup Operations

---

## Why SOC Analysts Care

Attackers often:

```text id="8h9j5n"
Create Task
      ↓

Disable Task
      ↓

Enable Task Later
      ↓

Payload Executes
```

or

```text id="vhsy9a"
Find Existing Task
      ↓

Enable Task
      ↓

Abuse Existing Trust
```

# Interview Answer

## Q: What does Event ID 4700 indicate?

### Answer

Event ID 4700 indicates that a previously disabled Scheduled Task was enabled. During investigation I would identify the task involved, determine its purpose, review who enabled it, correlate with 4698 task creation and 4701 task disable events, review related logon activity, and determine whether the task activation was legitimate administration or potential persistence activity.
