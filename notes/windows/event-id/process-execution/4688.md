# Windows Security Event ID 4688 - A New Process Has Been Created

## Overview

| Field       | Value                                                            |
| ----------- | ---------------------------------------------------------------- |
| Event ID    | 4688                                                             |
| Log Source  | Security                                                         |
| Category    | Process Creation                                                 |
| Severity    | Medium (Can become Critical depending on process)                |
| Description | Generated whenever a new process is created on a Windows system. |

---

## What Does It Mean?

Event ID 4688 indicates that a process was started on the system.

Think of Event ID 4688 as:

> "Something executed."

Every application launch generates 4688.

Examples:

```text
notepad.exe
chrome.exe
powershell.exe
cmd.exe
```

---

## Why Is It Important?

4688 helps analysts identify:

* Command execution
* Malware execution
* PowerShell activity
* Credential dumping
* Lateral movement
* Persistence mechanisms
* Privilege escalation activity

---

## Why SOC Analysts Care

Most attacker actions eventually create processes.

Example:

```text
4624
User Login
      ↓

4672
Admin Privileges
      ↓

4688
PowerShell.exe
      ↓

Malicious Activity
```

---

## Process Creation Flow

```text
User
 ↓

Application
 ↓

Windows Creates Process
 ↓

4688 Generated
```

---

## Example Event

```text
Creator Subject:
    Security ID: NT AUTHORITY\SYSTEM
    Account Name: name
    Account Domain: domain
    Logon ID: 0x3E7

Process Information:
    New Process ID: 0x2bb8

    New Process Name:
    C:\Program Files\...\exe

    Token Elevation Type:
    %%1936

    Mandatory Label:
    System Mandatory Level

    Creator Process ID:
    0x5c0

    Creator Process Name:
    C:\Program Files\kd.exe

    Process Command Line:
    "C:\Program Files\Sd\bin\kd-powershell.exe" --ps2
```

---

## Plain English Interpretation

This event means:

> Process kd-powershell.exe was started by parent process kd.exe under a SYSTEM-level security context.

# Process Creation Fundamentals

## What Is A Process?

A process is a running program.

Examples:

```text
chrome.exe
```

```text
powershell.exe
```

```text
cmd.exe
```

```text
notepad.exe
```

Every execution generates a process.

---

## Parent Child Relationship

One of the most important concepts.

Example:

```text
explorer.exe
      ↓
powershell.exe
      ↓
cmd.exe
```

Each process can create another process.

---

## Why It Matters

Attackers often abuse:

```text
powershell.exe
```

to launch:

```text
cmd.exe
```

which launches:

```text
rundll32.exe
```

The parent-child chain often reveals attacker behavior.

---


```text

```

Most powerful built-in Windows account.

---

## Why Analysts Care

SYSTEM processes have very high privileges.

Questions:

* Is SYSTEM expected?

* Is this software legitimate?

# Token Elevation Type

## Purpose

Indicates privilege level used by process.

---

## %%1936

Most common value.

Meaning:

```text
Full Elevated Token
```

Process has administrative privileges.

---

## %%1937

Meaning:

```text
Elevated Token Not Present
```

Standard user privileges.

---

## %%1938

Meaning:

```text
Limited Token
```

UAC restricted token.

---

## Investigation Notes

If:

```text
Token Elevation Type = %%1936
```

Questions:

* Is account admin?
* Is process expected?
* Is PowerShell involved?

---

# Mandatory Label

## Purpose

Integrity level of process.

Determines trust level.

---

## Common Values

| Label  | Meaning         |
| ------ | --------------- |
| Low    | Browser Sandbox |
| Medium | Standard User   |
| High   | Administrator   |
| System | Local System    |

---

## System Mandatory Level

Example:

```text
Mandatory Label\System Mandatory Level
```

Highest privilege level.

Equivalent to:

```text
NT AUTHORITY\SYSTEM
```

---

## Why Analysts Care

Attackers often attempt:

```text
Medium
      ↓
High
      ↓
System
```

Privilege escalation.

# Process Command Line

## Purpose

Shows exact execution command.

Most valuable field in Event ID 4688.

---

## Example

```text
"C:\Program Files\Sd\bin\kd-powershell.exe" --ps2
```

Shows:

* Executable
* Arguments
* Options

---

## Why Analysts Care

The command line often reveals attacker intent.

Examples:

```text
powershell.exe -enc
```

Encoded PowerShell.

---

```text
cmd.exe /c
```

Command execution.

---

```text
rundll32.exe
```

Potential LOLBIN abuse.

---

## Investigation Questions

* Are arguments expected?
* Is encoding used?
* Is remote execution involved?
* Is script execution occurring?
