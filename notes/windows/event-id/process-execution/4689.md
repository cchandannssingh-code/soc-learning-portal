# Windows Security Event ID 4689 - A Process Has Exited

## Overview

**Event ID:** 4689

**Log Source:** Security

**Category:** Process Tracking

**Description:** A process has exited.

---

## What Does It Mean?

Event ID 4689 is generated when a process terminates.

Think:

```text id="vpoc5d"
4688
=
Process Started

4689
=
Process Ended
```

---

## Why Is It Important?

4689 helps determine:

* Process Runtime
* Process Completion
* Suspicious Short-Lived Processes
* Malware Execution
* Script Execution
* Process Lifecycle

---

4688 tells us:

# Interview Answer

## Q: What does Event ID 4689 indicate?

### Answer

Event ID 4689 indicates that a process has terminated. During investigation I would correlate the event with Event ID 4688 using the Process ID, review the process name, calculate runtime, analyze the exit status, and determine whether the process behavior was expected or potentially malicious.

# Interview Questions

## Q: Why is Event ID 4689 important?

### Answer

Event ID 4689 records process termination. It helps determine whether a process completed successfully, how long it ran, and when it ended. When correlated with Event ID 4688, it provides the complete process lifecycle and is useful for investigating malware execution, PowerShell activity, privilege abuse, and attacker behavior.

---

## Q: Can 4689 be investigated alone?

### Answer

No. Event ID 4689 is most valuable when correlated with Event ID 4688 using the Process ID. Together they provide process start time, runtime, exit status, and execution context.
