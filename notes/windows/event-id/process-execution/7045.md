# Windows System Event ID 7045 - A Service Was Installed in the System

## Overview

**Event ID:** 7045

**Log Source:** System

**Provider:** Service Control Manager (SCM)

**Category:** Service Management

**Description:** A new Windows service was installed.

---

## What Does It Mean?

Event ID 7045 is generated when a new Windows service is installed on a system.

Think:

```text id="704501"
7045
=
New Service Created
```

The event is generated by:

```text id="704502"
Service Control Manager
(SCM)
```

---

## Why Is It Important?

Windows Services provide:

* Automatic Startup
* Persistence
* SYSTEM Privileges
* Background Execution

Because of this, attackers frequently create services.

---

## Why SOC Analysts Care

Service creation is one of the most common persistence mechanisms.

Common attack chain:

```text id="704503"
4624
Successful Login
      ↓

4672
Admin Privileges
      ↓

4688
Malicious Process
      ↓

7045
Service Installed
      ↓

Persistence
```

---

# Interview Questions

## Q: Why is Event ID 7045 important?

### Answer

Event ID 7045 indicates that a new Windows service was installed. Because services can start automatically and run with elevated privileges, attackers frequently use them for persistence, lateral movement, malware deployment, and ransomware execution. During investigation I would review the service name, executable path, startup type, service account, and related process creation events.

---

## Q: What field is most important in Event ID 7045?

### Answer

The most important field is usually:

```text id="704582"
Service File Name
```

because it reveals the executable that will run as the service.
